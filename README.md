# Likelion-toyproject-guestbook🤖

시간에 따라 테마가 바뀌는 방명록 웹 페이지  
방명록 작성, 조회, 수정, 삭제 기능 구현  
댓글 작성 및 삭제, 추천 기능 구현  

---

## 🔎Project Overview

HTML, CSS, JavaScript를 사용한 토이 프로젝트 방명록  
Django 백엔드와 연결하여 방명록 작성, 조회, 수정, 삭제 기능 구현  

시간대에 따라 낮, 노을, 밤 분위기로 화면 테마 변경  
모달창을 활용한 상세보기, 수정, 삭제, 댓글 작성 기능 구현  

---

## ✨Main Features

### 1. Create Guestbook

작성자, 비밀번호, 제목, 내용을 입력하여 방명록 작성

### 2. Read Guestbook List

작성된 방명록을 카드 형태로 목록 조회

### 3. Guestbook Detail

자세히 보기 버튼 클릭 시 모달창으로 방명록 상세 내용 조회

### 4. Update Guestbook

작성 시 입력한 비밀번호를 통해 방명록 제목과 내용 수정

### 5. Delete Guestbook

작성 시 입력한 비밀번호 확인 후 방명록 삭제

### 6. Create and Delete Comments

방명록 상세보기 화면에서 댓글 작성 및 삭제

### 7. Recommend Feature

방명록 추천 및 추천 취소 기능 구현

### 8. Search and Sort

제목, 작성자, 내용 기준 검색  
최신순, 추천순 정렬 기능 구현

### 9. Time-based Theme

현재 시간에 따라 낮, 노을, 밤 테마 변경

## 🕹️Feature Flow

| Feature | Description |
|---|---|
| Guestbook List | 작성된 방명록 목록 확인 |
| Create Guestbook | 제목, 작성자, 내용, 비밀번호 입력 후 작성 |
| Update Guestbook | 비밀번호 확인 후 제목과 내용 수정 |
| Delete Guestbook | 비밀번호 확인 후 방명록 삭제 |
| Create Comment | 방명록 상세보기 화면에서 댓글 작성 |
| Delete Comment | 비밀번호 확인 후 댓글 삭제 |
| Recommend | 방명록 추천 및 추천 취소 |
